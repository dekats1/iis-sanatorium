  # pricing-forecast

Сервис прогнозирования спроса и динамического ценообразования (FastAPI/Python).
Реализует гибридную модель ценообразования и прогноз загрузки Holt-Winters,
описанные в пояснительной записке (глава 2, раздел 2.1; глава 3, раздел 3.7).

> Написано и проверено логически (структура, типы, ограничения БД) в среде без
> доступа к PyPI/Maven — реально собрать и прогнать тесты нужно локально по
> шагам ниже. Это первое, что стоит сделать перед тем, как считать код готовым.

## Установка

```bash
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Требуется PostgreSQL 16+ с расширением `btree_gist` (создаётся миграцией автоматически).

## Переменные окружения (префикс `PRICING_`)

| Переменная                     | По умолчанию                                               | Назначение |
|---------------------------------|-------------------------------------------------------------|------------|
| `PRICING_DATABASE_URL`          | `postgresql+psycopg2://pricing:pricing@localhost:5432/sanatorium_pricing` | подключение к БД |
| `PRICING_JWT_SECRET`            | `dev-only-shared-secret-change-me-0123456789`                                    | общий секрет HS256 с core-service |
| `PRICING_RABBITMQ_URL`          | `amqp://guest:guest@localhost:5672/%2F`                      | брокер событий |
| `PRICING_QUOTE_TTL_MINUTES`     | `30`                                                          | срок жизни фиксированной котировки |
| `PRICING_REVIEW_AUTO_ACK_HOURS` | `24`                                                          | автоподтверждение записи рассмотрения |

Полный список — в `pricing_forecast/config.py`. Можно задать через `.env` в корне проекта.

## Миграции БД

```bash
alembic upgrade head
```

## Наполнение синтетическими данными

Реальных данных санатория нет (ограничение, раздел 1.2.1 главы 1), поэтому
используется CLI, а не HTTP-эндпоинт (замечание по безопасности — не оставлять
открытый сид в проде):

```bash
python -m pricing_forecast.cli seed        # демо-данные: сезоны, тарифы, коридоры, 24 мес. истории, прогнозы, рекомендации (идемпотентно; в docker compose запускается само)
python -m pricing_forecast.cli reseed       # пересоздать синтетические данные
python -m pricing_forecast.cli forecast 1   # прогноз для категории 1 вручную
```

## Запуск

```bash
uvicorn pricing_forecast.main:app --app-dir src --reload --port 8082
```

Consumer очереди RabbitMQ (отдельный процесс):

```bash
python -m pricing_forecast.events.rabbitmq
```
