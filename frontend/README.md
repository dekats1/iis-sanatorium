# frontend

React 19.3.0, TypeScript 7.0.2, Vite 8.3.4, react-router-dom 7.18.4, vitest 5.0.5. Чёрно-белое оформление, пригодное для печати.

```bash
npm install
npm run dev        # http://localhost:5173, запросы /api и /pricing проксируются на gateway :8080
npm run build      # tsc --noEmit && vite build (проверено)
npm test           # vitest: разбор JWT, API-клиент (проверено)
```

| Страница | Роль | Требования |
|---|---|---|
| `LoginPage` — вход, регистрация клиента | все | ФТ-01 |
| `SearchPage`, `BookingPage` — поиск, цена, оформление путёвки, лист ожидания | CLIENT, BOOKING_ADMIN | ФТ-05…ФТ-08, ФТ-11 |
| `MyBookingsPage` — путёвки и платежи клиента, оплата, отмена | CLIENT | ФТ-08, ФТ-09, ФТ-19 |
| `AdminBookingsPage` — карточки клиентов и состояния здоровья, заселение/выселение, отмена, лист ожидания | BOOKING_ADMIN | ФТ-04, ФТ-09…ФТ-11 |
| `DoctorPage` — назначения, противопоказания, расписание, отметка выполнения | DOCTOR | ФТ-12…ФТ-14 |
| `ManagerDashboardPage` — KPI, каналы, прогноз, коридор цен, рекомендации вне коридора | MANAGER | ФТ-15…ФТ-18 |
| `AdminPage` — пользователи и роли, журнал, справочники (только просмотр) | SYSADMIN | ФТ-02, ФТ-03 (частично), ФТ-20 |

Не покрыто интерфейсом: перенос брони (в core-service его нет), правка справочников (только REST API), тарифы и сезоны (ФТ-16: в интерфейсе
только коридор цен; остальное — REST API pricing-forecast), отдельная история платежей клиента (в таблице путёвок показана оплаченная сумма).

Токен хранится в `sessionStorage` (живёт до закрытия вкладки). Это доступно скриптам страницы (риск XSS) — осознанное упрощение
прототипа; в промышленной версии — HttpOnly-cookie. Разбор JWT в браузере нужен только для интерфейса (имя, меню), подпись проверяют
шлюз и сервисы. Скрытие разделов по роли (`ProtectedRoute`) — удобство, а не защита.

Образ (`Dockerfile`): сборка в `node:24-alpine`, раздача `nginx:stable-alpine`; nginx проксирует `/api/` и `/pricing/` на gateway и
перезаписывает `X-Forwarded-For`. Образ не собирался (Docker недоступен в среде разработки).
